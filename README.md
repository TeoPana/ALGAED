# ALGAED

Materiale pentru cursul de Algebră Liniară, Geometrie Analitică și Ecuații Diferențiale (anul I).

## Structură

- **`GHIDURI/`** — ghiduri de recapitulare interactive (HTML, deschide direct în browser):
  - `cram-algaed.html` — sesiune de cram înaintea examenului final: 5 tipuri de subiecte (sisteme de ecuații diferențiale, ecuații diferențiale de ordin 2, proiecție/complement ortogonal, SVD, conice), fiecare cu rezolvare pas cu pas, exercițiu de antrenament cu verificare automată a răspunsului și un quiz final de recunoaștere a tipului de problemă.
  - `ghid-examen-algaed.html` — ghid de referință pentru materia de examen final.
  - `ghid-partial-algaed.html` — ghid de referință pentru materia de parțial.
  - `svd-explicat.html` — rețeta pentru descompunerea valorilor singulare (P3), cu exercițiul 1(d) rezolvat complet pas cu pas.
  - `conica-explicata.html` — rețeta pentru reducerea unei conice la forma canonică, rotație + translație (P2), cu exercițiul 6(a) rezolvat complet pas cu pas.
- **`CURSURI/`** — cursurile 1–18, în format PDF.
- **`SEMINARE/`** — materiale de seminar.
- **`EXERCITII/`** — fișe de exerciții pe teme, grupate pe autor (`BADRALEXI/`, `CANEPA/`); `CANEPA/REZOLVATE/` conține exerciții cu soluții complete.
- **`SUBIECTE/`** — subiecte de parțial și examen din anii anteriori (2021–2025), inclusiv barem oficial unde există.
- **`TEORIE/`** — sinteze de teorie și formule.
- **`MATERIALE PROFESOR/`** — cursul și culegerea de exerciții ale profesorului, în format extins (PDF).

## Cum folosești ghidurile

Deschide oricare fișier din `GHIDURI/` direct într-un browser (dublu-click sau `file://` local) — sunt pagini HTML de sine stătătoare, fără dependențe externe în afară de fonturi. `cram-algaed.html` e gândit pentru recapitulare intensivă, condensată, chiar înainte de examen.
