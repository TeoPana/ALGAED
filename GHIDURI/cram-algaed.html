Trei mișcări

  1. Omogena. Ecuația caracteristică λ² + aλ + b = 0 → scrii x₀ după tipul rădăcinilor.
  2. Particulara. Ghicești forma lui x_p după cum arată dreapta, o înlocuiești și afli coeficientul.

OMOGENA PARTICULARA (m = de câte ori e μ rădăcină) λ₁ ≠ λ₂ : C₁e^(λ₁t) + C₂e^(λ₂t) dreapta = k → x_p = a·tᵐ λ dublă : (C₁ + C₂t)·e^(λt) dreapta = e^(μt) → x_p = a·tᵐ·e^(μt) α ± iβ : e^(αt)(C₁cos βt + C₂sin βt) dreapta = cos/sin ωt → x_p = tᵐ(a cos + b sin)

Vezi-o făcută — examen 23.01.2023

x″ + 4x′ + 4x = 4,  x(0) = 0,  x′(0) = 0.

Mișcarea 1 — omogena
λ² + 4λ + 4 = 0 ⟹ (λ + 2)² = 0 ⟹ λ = −2, rădăcină DUBLĂ ⟹ x₀ = (C₁ + C₂·t)·e^(−2t)
Mișcarea 2 — particulara

Dreapta e constanta 4. Constanta corespunde lui μ = 0, iar 0 nu e rădăcină aici (rădăcina e −2), deci m = 0 și încerci direct o constantă:

x_p = a ⟹ x_p′ = 0, x_p″ = 0 înlocuind : 0 + 0 + 4a = 4 ⟹ a = 1
Mișcarea 3 — constantele
x(t) = (C₁ + C₂t)·e^(−2t) + 1 x(0) = C₁ + 1 = 0 ⟹ C₁ = −1 x′(t) = (C₂ − 2C₁ − 2C₂t)·e^(−2t) ← derivezi produsul! x′(0) = C₂ − 2C₁ = C₂ + 2 = 0 ⟹ C₂ = −2 x(t) = 1 − (1 + 2t)·e^(−2t) verificare: x(0) = 1 − 1 = 0 ✓

Acum tu

x″ − 3x′ + 2x = 4 , x(0) = 1 , x′(0) = 0
λ² − 3λ + 2 = 0 ⟹ (λ−1)(λ−2) = 0 ⟹ λ = 1, λ = 2 (distincte) x₀ = C₁e^t + C₂e^(2t) dreapta = 4, iar 0 nu e rădăcină ⟹ x_p = a înlocuind: 0 − 0 + 2a = 4 ⟹ a = 2 x(t) = C₁e^t + C₂e^(2t) + 2 x(0) = C₁ + C₂ + 2 = 1 ⟹ C₁ + C₂ = −1 x′(t) = C₁e^t + 2C₂e^(2t) x′(0) = C₁ + 2C₂ = 0 ⟹ C₁ = −2C₂ −2C₂ + C₂ = −1 ⟹ C₂ = 1, C₁ = −2 x(t) = −2e^t + e^(2t) + 2 verificare: x(0) = −2+1+2 = 1 ✓

Rezonanța — capcana care apare cel mai des

Dacă exponentul din dreapta este chiar o rădăcină a ecuației caracteristice, forma simplă nu funcționează: substituția îți dă 0 = ceva. Atunci înmulțești cu t.

x″ − x = eᵗ λ² − 1 = 0 ⟹ λ = ±1 μ = 1 ESTE rădăcină (m = 1) ⟹ x_p = a·t·eᵗ x_p′ = a(eᵗ + t·eᵗ) x_p″ = a(2eᵗ + t·eᵗ) x_p″ − x_p = 2a·eᵗ = eᵗ ⟹ a = ½ ⟹ x_p = (t/2)·eᵗ

Ce te poate costa

  • La λ dublă, x′ se obține derivând un produs — nu uita termenul care vine din C₂t.
  • La ecuațiile cuplate, rezolvi complet ecuația de ordin I întâi, apoi îi bagi rezultatul ca termen liber în a doua.
  • x′(0) se calculează derivând soluția completă, cu tot cu x_p.

Trei mișcări

Vezi-o făcută — examen ianuarie 2024

Mișcarea 2 — Gram–Schmidt
w₁ = u₁ = (0,1,2,−2) ‖w₁‖² = 0+1+4+4 = 9 ⟨u₃,w₁⟩ = 0·1 + 1·1 + 4·2 + 0·(−2) = 9 w₂ = u₃ − (9/9)·w₁ = (1,1,4,0) − (0,1,2,−2) = (1, 0, 2, 2) ‖w₂‖² = 1+0+4+4 = 9
Mișcarea 3 — proiecția
⟨v,w₁⟩ = 0 + 0 + 2 + 0 = 2 ⟨v,w₂⟩ = 1 + 0 + 2 + 0 = 3 pr_U v = (2/9)·(0,1,2,−2) + (3/9)·(1,0,2,2) = (0, 2/9, 4/9, −4/9) + (1/3, 0, 2/3, 2/3) = (1/9)·(3, 2, 10, 2) pr_(U⊥) v = (1,0,1,0) − (1/9)(3,2,10,2) = (1/9)·(6, −2, −1, −2)
Dacă cere U⊥ explicit

Pui produsul scalar cu fiecare generator egal cu zero:

x = (x,y,z,t) ⟨x,u₁⟩ = 0 : y + 2z − 2t = 0 ⟨x,u₃⟩ = 0 : x + y + 4z = 0 ⟹ x = −2z − 2t , y = −2z + 2t (z, t libere) dim U⊥ = 4 − 2 = 2 , bază { (−2,−2,1,0), (−2,2,0,1) }

Acum tu — numerele ies întregi, nu te speria de fracții

U = Sp{ u₁=(1,1,1,1), u₂=(3,1,1,−1), u₃=(4,2,2,0) } v = (4,0,0,0)
1) u₁ + u₂ = (4,2,2,0) = u₃ ⟹ u₃ dependent, îl arunci. dim U = 2 2) w₁ = (1,1,1,1), ‖w₁‖² = 4 ⟨u₂,w₁⟩ = 3+1+1−1 = 4 w₂ = (3,1,1,−1) − (4/4)(1,1,1,1) = (2, 0, 0, −2), ‖w₂‖² = 8 3) ⟨v,w₁⟩ = 4 ⟨v,w₂⟩ = 8 pr_U v = (4/4)(1,1,1,1) + (8/8)(2,0,0,−2) = (1,1,1,1) + (2,0,0,−2) = (3, 1, 1, −1) pr_(U⊥) v = (4,0,0,0) − (3,1,1,−1) = (1, −1, −1, 1) verificare: (1,−1,−1,1)·u₁ = 0 ✓ , (1,−1,−1,1)·u₂ = 3−1−1−1 = 0 ✓

Ce te poate costa

  • Dacă sari peste mișcarea 1 și faci Gram–Schmidt pe trei vectori dependenți, îți iese w₃ = 0 și crezi că ai greșit. Nu ai — doar erau dependenți.
  • La proiecție se împarte la ‖wᵢ‖², nu la ‖wᵢ‖.
  • Nu normaliza dacă nu ți se cere „ortonormată" — radicalii doar îngreunează calculul.
  • Verificarea gratuită: pr_(U⊥) v trebuie să dea produs scalar zero cu fiecare generator.
