Ghid de examen ALGAED

Nouă tipuri de exerciții acoperă tot ce a picat între 2021 și 2025. Pentru fiecare: rețeta în pași, un exemplu rezolvat cu numerele reale de pe subiect, și capcanele. Nimic în plus.

Harta examenului

Subiectele au aceeași structură an de an. Examenul final are 5 probleme, parțialul are 4 — iar restanța înseamnă structura de examen final. Coloana din dreapta spune în câte din sesiunile 2021–2025 a apărut tipul respectiv.

Planul de învățat

Ordinea nu e cea din curs, e cea a raportului punctaj / efort. Diagonalizarea e prima fiindcă P2, P3 și P4 de la examen se sprijină toate pe ea — o înveți o dată, o folosești de trei ori.

Sesiunea 1 · 2h

Diagonalizare + cele două ecuații diferențiale (P4, P5). Sunt 40% din examenul final și sunt complet mecanice — se rezolvă la fel de fiecare dată. Refă cu mâna, pe hârtie, cele trei exemple de mai jos.

Sesiunea 2 · 2h

Proiecție / Gram–Schmidt (P1) și SVD (P3). Amândouă sunt „calculează valori proprii, apoi ortogonalizează" — dacă ai făcut sesiunea 1, valorile proprii le știi deja.

Sesiunea 3 · 1½h

Conica (P2) — are cei mai mulți pași, dar se punctează pe parcurs: doar identificarea tipului cu δ îți aduce puncte. Apoi recitește capcanele de la toate tipurile.

Dacă e parțial

Fă în schimb cele 4 tipuri din a doua jumătate a ghidului. Diagonalizarea rămâne prima.

Examen final — cele 5 probleme

P1 apare la fiecare sesiune

Complement ortogonal și proiecție

Model: examen ianuarie 2024, grupa CC

Rețeta

  1. Verifică întâi dacă generatorii lui U sunt independenți. Dacă unul e combinație a celorlalți, aruncă-l. dim U = câți rămân.
  2. Gram–Schmidt pe cei rămași: fiecare vector nou minus proiecțiile lui pe toți cei deja ortogonalizați.
  3. Proiecția: aduni proiecțiile lui v pe fiecare vector din baza ortogonală.
  4. pr_{U⊥} v = v − pr_U v. Nu îl recalcula de la zero.
  5. Dacă cere explicit U⊥: rezolvi sistemul ⟨x, uᵢ⟩ = 0 pentru fiecare generator. dim U⊥ = n − dim U.
w₁ = u₁ w₂ = u₂ − (⟨u₂,w₁⟩ / ‖w₁‖²)·w₁ w₃ = u₃ − (⟨u₃,w₁⟩ / ‖w₁‖²)·w₁ − (⟨u₃,w₂⟩ / ‖w₂‖²)·w₂ pr_U v = Σᵢ (⟨v,wᵢ⟩ / ‖wᵢ‖²)·wᵢ

Exemplu rezolvat

Se dă: U = Sp{u₁=(0,1,2,−2), u₂=(1,2,6,−2), u₃=(1,1,4,0)} ⊆ ℝ⁴ și v = (1,0,1,0). Se cer U⊥ și prUv.

1. Dependență. Observi că u₁ + u₃ = (1,2,6,−2) = u₂. Deci u₂ se aruncă: dim U = 2, bază {u₁, u₃}.

2. Gram–Schmidt.

w₁ = u₁ = (0,1,2,−2), ‖w₁‖² = 0+1+4+4 = 9 ⟨u₃,w₁⟩ = 0+1+8+0 = 9 w₂ = (1,1,4,0) − (9/9)(0,1,2,−2) = (1,0,2,2), ‖w₂‖² = 9

3. Proiecția. ⟨v,w₁⟩ = 0+0+2+0 = 2 și ⟨v,w₂⟩ = 1+0+2+0 = 3.

pr_U v = (2/9)(0,1,2,−2) + (3/9)(1,0,2,2) = (1/9)·(3, 2, 10, 2)

4. Complementul.

pr_(U⊥) v = (1,0,1,0) − (1/9)(3,2,10,2) = (1/9)·(6, −2, −1, −2)

5. U⊥ explicit. Din ⟨x,u₁⟩ = 0 și ⟨x,u₃⟩ = 0, cu x = (x,y,z,t):

y + 2z − 2t = 0 x + y + 4z = 0 ⟹ x = −2z − 2t, y = −2z + 2t dim U⊥ = 2, bază { (−2,−2,1,0), (−2,2,0,1) }

Capcane

  • Dacă faci Gram–Schmidt fără să verifici dependența, îți iese w₃ = 0 și te blochezi. Verifică întâi.
  • Nu normaliza dacă enunțul cere doar „bază ortogonală" — radicalii complică degeaba calculul proiecției.
  • La proiecție se împarte la ‖wᵢ‖², nu la ‖wᵢ‖.
P2 apare la fiecare sesiune

Conică: tip și formă canonică

Model: examen ianuarie 2024, grupa CC

Rețeta

  1. Identifică coeficienții din forma standard. Atenție: coeficientul lui xy se împarte la 2 ca să obții a₁₂; la fel pentru b₁, b₂.
  2. Calculează δ — asta îți dă tipul, și e deja punctaj.
  3. Calculează Δ — dacă e ≠ 0, conica e nedegenerată.
  4. Diagonalizează A: valori proprii λ₁, λ₂ și vectori proprii normalizați. Formează Q cu det Q = +1 (dacă iese −1, inversează cele două coloane).
  5. Substituie (x,y)ᵀ = Q(x′,y′)ᵀ. Partea pătratică devine automat λ₁x′² + λ₂y′²; partea liniară se recalculează.
  6. Formează pătrate perfecte (translația) și scrii forma canonică.
a₁₁x² + 2a₁₂xy + a₂₂y² + 2b₁x + 2b₂y + c = 0 | a₁₁ a₁₂ | | a₁₁ a₁₂ b₁ | δ = | | Δ = | a₁₂ a₂₂ b₂ | | a₁₂ a₂₂ | | b₁ b₂ c | δ > 0 → elipsă δ = 0 → parabolă δ < 0 → hiperbolă Δ ≠ 0 → nedegenerată Δ = 0 → degenerată

Exemplu rezolvat

Se dă: x² + 2xy + y² + 2x − 2y = 0. Se cer tipul și forma canonică.

1. Coeficienții. a₁₁ = 1, a₁₂ = 1 (jumătate din 2), a₂₂ = 1, b₁ = 1, b₂ = −1, c = 0.

2–3. Tipul.

δ = 1·1 − 1·1 = 0 ⟹ parabolă Δ = det[1 1 1; 1 1 −1; 1 −1 0] = −4 ≠ 0 ⟹ nedegenerată

4. Rotația. A = [1 1; 1 1], deci λ² − 2λ = 0 ⟹ λ₁ = 2, λ₂ = 0.

λ=2 : −x + y = 0 ⟹ q₁ = (1,1)/√2 λ=0 : x + y = 0 ⟹ q₂ = (−1,1)/√2 1 | 1 −1 | Q = ——— | |, det Q = ½(1+1) = 1 ✓ √2 | 1 1 |

5. Substituția. x = (x′−y′)/√2 și y = (x′+y′)/√2.

partea pătratică → λ₁x′² + λ₂y′² = 2x′² partea liniară → 2x − 2y = (2/√2)[(x′−y′) − (x′+y′)] = −2√2·y′

6. Forma canonică.

2x′² − 2√2·y′ = 0 ⟹ y′ = x′²/√2 (parabolă)

Capcane

  • Cel mai frecvent greșit: a₁₂ este jumătate din coeficientul lui xy. La fel b₁, b₂.
  • det Q trebuie să fie +1. Dacă e −1, ai o simetrie, nu o rotație — schimbă coloanele între ele.
  • Verificări rapide fără calcul: apare doar x² (nu și y²) → parabolă; x² și y² cu semne diferite → hiperbolă; cu același semn și coeficienți egali → cerc.
P3 apare la fiecare sesiune

Descompunerea SVD

Model: examen ianuarie 2024, ambele grupe (CC și CD)

Rețeta

  1. Dacă ți se dă o aplicație f, nu o matrice, prima treabă e să scrii matricea A în baza canonică — pe coloane pui imaginile vectorilor din bază.
  2. Calculează M = AᵀA (iese simetrică, n×n).
  3. Valorile proprii ale lui M sunt mereu ≥ 0. Ordonează-le descrescător; vectorii proprii ortonormați, în aceeași ordine, sunt coloanele lui V.
  4. σᵢ = √λᵢ. Σ are aceeași formă (m×n) ca A, cu σ pe diagonală și 0 în rest.
  5. uᵢ = (1/σᵢ)·A·vᵢ, pentru fiecare σᵢ ≠ 0.
  6. Dacă ai obținut mai puțini uᵢ decât m, completează cu vectori ortonormați oarecare.
A = U · Σ · Vᵀ

Exemplu rezolvat

Se dă: f : ℝ₂[X] → ℝ₂[X], f(P) = P′ (derivata), în baza canonică {1, X, X²}. Se cere SVD.

1. Matricea. f(1) = 0, f(X) = 1, f(X²) = 2X. Coordonatele acestora, puse pe coloane:

| 0 1 0 | A = | 0 0 2 | | 0 0 0 |

2–3. AᵀA și spectrul.

| 0 0 0 | AᵀA = | 0 1 0 | λ₁ = 4, λ₂ = 1, λ₃ = 0 | 0 0 4 | v₁ = (0,0,1), v₂ = (0,1,0), v₃ = (1,0,0) | 0 0 1 | V = | 0 1 0 | (ordinea: λ descrescător) | 1 0 0 |

4. Valorile singulare. σ₁ = √4 = 2, σ₂ = √1 = 1, σ₃ = 0 ⟹ Σ = diag(2, 1, 0).

5–6. Matricea U.

u₁ = ½·A·(0,0,1)ᵀ = ½·(0,2,0) = (0,1,0) u₂ = 1·A·(0,1,0)ᵀ = (1,0,0) u₃ = (0,0,1) (completat ortonormal) | 0 1 0 | U = | 1 0 0 | | 0 0 1 |

Capcane

  • σ = √λ, nu λ.
  • Coloanele lui V se ordonează după λ descrescător — altfel Σ nu mai corespunde.
  • Σ are dimensiunea lui A (m×n), nu a lui AᵀA. Dacă A nu e pătratică, Σ are linii sau coloane de zerouri.
P4 apare la fiecare sesiune · cea mai sigură

Sistem de 2 ecuații diferențiale (Cauchy)

Model: examen ianuarie 2024, grupa CC

Rețeta

  1. Scrie sistemul ca X′ = A·X, cu A matricea coeficienților.
  2. Valorile proprii ale lui A. De aici, unul din trei cazuri (mai jos).
  3. Dacă sistemul are termen liber (neomogen): caută întâi o soluție particulară constantă, rezolvând A·X + b = 0, și adaug-o la soluția omogenă.
  4. Pune t = 0 în soluția generală și obții un sistem în C₁, C₂.
  5. Partea geometrică: taie Ox ⟺ y(t) = 0; taie Oy ⟺ x(t) = 0; bisectoarea I ⟺ y = x; bisectoarea a II-a ⟺ y = −x. Tangenta într-un punct t₀ este vectorul (x′(t₀), y′(t₀)).
λ₁ ≠ λ₂ reale X(t) = C₁e^(λ₁t)·v₁ + C₂e^(λ₂t)·v₂ λ dublă, un găsești v₂ din (A − λI)v₂ = v₁ , apoi singur vector X(t) = C₁e^(λt)·v₁ + C₂e^(λt)·(t·v₁ + v₂) λ = α ± iβ X(t) = e^(αt)·[ combinații de cos βt și sin βt ]

Exemplu rezolvat

Se dă: x′ = 3x − y, y′ = −x + 3y, cu x(0) = 0, y(0) = 2. Se cere soluția și dacă intersectează axele.

1–2. Spectrul.

| 3 −1 | A = | | det(A − λI) = (3−λ)² − 1 = 0 ⟹ λ = 2, 4 | −1 3 | λ=2 : x − y = 0 ⟹ v₁ = (1, 1) λ=4 : −x − y = 0 ⟹ v₂ = (−1, 1)

3. Soluția generală. Valori proprii distincte, deci primul caz:

X(t) = C₁·e^(2t)·(1,1) + C₂·e^(4t)·(−1,1)

4. Condițiile inițiale. La t = 0: C₁ − C₂ = 0 și C₁ + C₂ = 2, deci C₁ = C₂ = 1.

x(t) = e^(2t) − e^(4t) y(t) = e^(2t) + e^(4t)

5. Geometria.

Ox : y(t) = e^(2t) + e^(4t) > 0 pentru orice t ⟹ NU intersectează Ox Oy : x(t) = 0 ⟺ e^(2t) = e^(4t) ⟺ t = 0 ⟹ intersectează Oy în punctul (0, 2) tangenta în t=0 : (x′(0), y′(0)) = (2−4, 2+4) = (−2, 6) nu e paralelă cu (0,1) ⟹ curba NU e tangentă la Oy

Capcane

  • Condițiile inițiale se pun în soluția generală deja scrisă, nu în ecuația de pornire.
  • Înainte să spui „intersectează", verifică semnul: e^(2t) − e^(4t) este negativ pentru orice t > 0.
  • La cazul cu λ dublă, v₂ se găsește din (A − λI)v₂ = v₁ — cu v₁ în dreapta, nu cu 0.
P5 apare la fiecare sesiune · ultima problemă

Ecuație diferențială de ordin 2 (Cauchy)

Model: examen 23.01.2023 și examen ianuarie 2024

Rețeta

  1. Ecuația caracteristică: x″ + ax′ + bx = f(t) devine λ² + aλ + b = 0.
  2. Soluția omogenă x₀, după tipul rădăcinilor (tabelul de mai jos).
  3. Soluția particulară xp, după forma lui f(t) (al doilea tabel).
  4. x = x₀ + x_p, apoi pui x(0) și x′(0).
SOLUȚIA OMOGENĂ λ₁ ≠ λ₂ reale x₀ = C₁e^(λ₁t) + C₂e^(λ₂t) λ dublă x₀ = (C₁ + C₂t)·e^(λt) λ = α ± iβ x₀ = e^(αt)·(C₁cos βt + C₂sin βt) SOLUȚIA PARTICULARĂ (m = multiplicitatea lui λ ca rădăcină; 0 dacă nu e rădăcină) f = constantă k x_p = a·tᵐ f = e^(μt) x_p = a·tᵐ·e^(μt) f = polinom gr. n x_p = polinom de grad n, înmulțit cu tᵐ f = cos ωt/sin ωt x_p = tᵐ·(a·cos ωt + b·sin ωt)

Exemplu rezolvat A — termen liber constant

Se dă: x″ + 4x′ + 4x = 4, cu x(0) = 0, x′(0) = 0.

λ² + 4λ + 4 = 0 ⟹ (λ+2)² = 0 ⟹ λ = −2 dublă x₀ = (C₁ + C₂t)·e^(−2t) f = 4 constantă, iar 0 nu e rădăcină ⟹ x_p = a substitui: 4a = 4 ⟹ a = 1 x(t) = (C₁ + C₂t)·e^(−2t) + 1 x(0) = C₁ + 1 = 0 ⟹ C₁ = −1 x′(t) = (C₂ − 2C₁ − 2C₂t)e^(−2t) x′(0) = C₂ − 2C₁ = C₂ + 2 = 0 ⟹ C₂ = −2 x(t) = 1 − (1 + 2t)·e^(−2t)

Exemplu rezolvat B — ecuații cuplate

Se dă: x″ + 4x = 5f(t), cu x(0) = 0, x′(0) = 1, unde f este soluția lui f′ + 4f = 5eᵗ, f(0) = 1.

Întâi f (ecuație de ordin I):

f₀ = C·e^(−4t); f_p = a·eᵗ ⟹ a + 4a = 5 ⟹ a = 1 f(0) = C + 1 = 1 ⟹ C = 0 ⟹ f(t) = eᵗ

Apoi x, cu 5f(t) = 5eᵗ ca termen liber:

λ² + 4 = 0 ⟹ λ = ±2i ⟹ x₀ = C₁cos 2t + C₂sin 2t x_p = a·eᵗ ⟹ a + 4a = 5 ⟹ a = 1 x(t) = C₁cos 2t + C₂sin 2t + eᵗ x(0) = C₁ + 1 = 0 ⟹ C₁ = −1 x′(0) = 2C₂ + 1 = 1 ⟹ C₂ = 0 x(t) = eᵗ − cos 2t

Capcane

  • Rezonanța. Dacă μ (respectiv ±iω) este rădăcină a ecuației caracteristice, înmulțește xp cu tᵐ. Fără asta, substituția îți dă 0 = ceva și te blochezi.
  • La ecuațiile cuplate, rezolvi complet ecuația de ordin I întâi, apoi o bagi ca termen liber în a doua.
  • x′(0) se calculează derivând soluția completă, inclusiv xp.

P1 3 din 4 sesiuni

Geometrie analitică în spațiu

Model: parțial CC 2022 (reapare aproape identic în decembrie 2024)

Rețeta

  1. Din fiecare dreaptă scoate un punct și vectorul director: din (x−x₀)/a = (y−y₀)/b = (z−z₀)/c ai M₀(x₀,y₀,z₀) și v = (a,b,c).
  2. Concurente ⟺ coplanare și neparalele ⟺ produsul mixt (v₁, v₂, M₁M₂) = 0. De aici scoți parametrul.
  3. Planul determinat de ele trece prin M₁ și are normala N = v₁ × v₂.
  4. Simetricul lui A față de plan: scrii dreapta prin A cu direcția N, afli intersecția P cu planul, iar simetricul este B = 2P − A.
  5. Aria triunghiului: ½·‖AB × AC‖.

Exemplu rezolvat

Se dă: d₁ : (x−2)/4 = (y+1)/α = z/2 și d₂ : (x+1)/3 = y/2 = (z−2)/4. Se cere α pentru care sunt concurente, plus ecuația planului.

M₁(2,−1,0), v₁ = (4, α, 2) M₂(−1,0,2), v₂ = (3, 2, 4) M₁M₂ = (−3, 1, 2) | 4 α 2 | (v₁,v₂,M₁M₂) = | 3 2 4 | = 4(4−4) − α(6+12) + 2(3+6) = 18 − 18α |−3 1 2 | = 0 ⟹ α = 1

Cu α = 1, normala planului:

N = v₁ × v₂ = (1·4 − 2·2, −(4·4 − 2·3), 4·2 − 1·3) = (0, −10, 5) π : 0(x−2) − 10(y+1) + 5(z−0) = 0 ⟹ 2y − z + 2 = 0 verificare: M₂(−1,0,2) → 0 − 2 + 2 = 0 ✓

Capcane

  • Componenta din mijloc a produsului vectorial are semn minus în față.
  • Produsul mixt = 0 înseamnă coplanare, care poate însemna și paralele. Verifică rapid că v₁ și v₂ nu sunt proporționale.
  • La final, verifică planul cu al doilea punct: prinde greșelile de semn.
P2 apare la fiecare parțial

Dependență liniară cu parametru, completare la bază, coordonate

Model: parțial CC 2022. Aceeași problemă, cu polinoame în loc de matrice, a picat în 2023 și în decembrie 2024 — se rezolvă identic.

Rețeta

  1. Scrie fiecare matrice sau polinom ca vector de coordonate în baza canonică. Pentru M₂(ℝ): (a₁₁, a₁₂, a₂₁, a₂₂). Pentru ℝ₃[X]: (a₀, a₁, a₂, a₃). De aici totul e algebră liniară obișnuită.
  2. Pune vectorii pe liniile unei matrice: dependenți ⟺ det = 0. Rezolvi în parametru.
  3. Cu parametrul găsit, caută relația concretă de dependență și aruncă un vector. Ce rămâne e o bază pentru Sp{...}.
  4. Completare la o bază a spațiului: adaugi vectori din baza canonică (E₁₁, E₁₂, … sau 1, X, X², X³) până la dimensiunea spațiului, și verifici det ≠ 0.
  5. Coordonatele lui B: rezolvi sistemul α₁b₁ + … + αₙbₙ = B. Începe cu componentele care apar în cele mai puține ecuații.

Exemplu rezolvat

Se dă: A₁ = (4 3; 2 1), A₂ = (β −3; 2 −1), A₃ = (1 0; 1 0), A₄ = (0 1; 0 1) în M₂(ℝ), și B = (5 4; 3 2).

1–2. Parametrul. Ca vectori de coordonate:

A₁=(4,3,2,1) A₂=(β,−3,2,−1) A₃=(1,0,1,0) A₄=(0,1,0,1) | 4 3 2 1 | | β −3 2 −1 | | 1 0 1 0 | = −2β = 0 ⟹ β = 0 | 0 1 0 1 |

3. Relația de dependență. Cu β = 0:

A₁ + A₂ = (4,0,4,0) = 4·A₃ ⟹ A₁ + A₂ − 4A₃ = 0 dim Sp{A₁,A₂,A₃,A₄} = 3, bază { A₁, A₃, A₄ }

4. Completarea. M₂(ℝ) are dimensiunea 4, deci adaug un vector — de exemplu E₁₁ = (1,0,0,0):

| 4 3 2 1 | | 1 0 1 0 | | 0 1 0 1 | = −2 ≠ 0 ⟹ { A₁, A₃, A₄, E₁₁ } e bază în M₂(ℝ) | 1 0 0 0 |

5. Coordonatele lui B. Din α·A₁ + γ·A₃ + δ·A₄ + ε·E₁₁ = (5,4,3,2), luate pe componente:

a₂₂ : α + δ = 2 a₁₂ : 3α + δ = 4 ⟹ α = 1, δ = 1 a₂₁ : 2α + γ = 3 ⟹ γ = 1 a₁₁ : 4α + γ + ε = 5 ⟹ ε = 0 [B] = (1, 1, 1, 0)ᵀ adică B = A₁ + A₃ + A₄

Capcane

  • Nu încerca să lucrezi direct cu matricele. Trecerea la vectori de coordonate transformă problema în ceva mecanic.
  • Baza pentru Sp{...} nu e formată din toți cei patru — e formată din cei rămași după ce arunci vectorul dependent.
  • Când completezi baza, verifică întotdeauna determinantul. Un vector canonic ales prost poate fi deja în subspațiu.
P3 3 din 4 sesiuni

Aplicație liniară cu parametru: Ker, Im, sumă directă

Model: parțial CC 2022 (reapare cu semne schimbate în 2023)

Rețeta

  1. M(f) are pe coloane imaginile vectorilor bazei canonice.
  2. det M(f) = 0 îți dă valorile speciale ale parametrului. Factorizează determinantul, nu-l lăsa desfăcut.
  3. Pentru parametru generic (det ≠ 0): rang 3, Ker = {0}, Im = ℝ³, f bijectivă.
  4. Pentru fiecare valoare specială: calculezi rangul, apoi Ker (soluțiile sistemului omogen) și Im (coloanele independente). Verifică mereu dim Ker + dim Im = 3.
  5. Sumă directă ⟺ Ker ∩ Im = {0}: iei generatorul lui Ker și vezi dacă satisface ecuația care descrie Im.

Exemplu rezolvat

Se dă: f(x,y,z) = (γx + y + z, x + γy + z, x + y + γz). Se cer Ker și Im, discuție după γ, și dacă suma Ker ⊕ Im e directă.

| γ 1 1 | M(f)=| 1 γ 1 | det = γ³ − 3γ + 2 = (γ − 1)²·(γ + 2) | 1 1 γ |

Cazul γ ∉ {1, −2}: rang 3, Ker = {0}, Im = ℝ³, f bijectivă.

Cazul γ = 1: matricea are toate elementele 1, deci rang 1.

Ker : x + y + z = 0 ⟹ dim 2, bază {(1,−1,0), (1,0,−1)} Im : Sp{(1,1,1)} ⟹ dim 1 (2 + 1 = 3 ✓)

Cazul γ = −2: minorul |−2 1; 1 −2| = 3 ≠ 0, deci rang 2.

Ker : Sp{(1,1,1)} ⟹ dim 1 (−2+1+1 = 0 ✓) Im : planul x + y + z = 0 ⟹ dim 2 (coloanele au suma 0)

Suma directă. În ambele cazuri speciale, unul dintre subspații este dreapta Sp{(1,1,1)} și celălalt este planul x+y+z = 0. Cum 1+1+1 = 3 ≠ 0, vectorul (1,1,1) nu e în plan:

Ker ∩ Im = {0} pentru orice γ ⟹ ℝ³ = Ker(f) ⊕ Im(f) întotdeauna

Capcane

  • Cele două cazuri speciale se confundă ușor între ele: la γ = 1 rangul e 1 (matricea e plină de 1-uri), la γ = −2 rangul e 2. Verifică rangul, nu-l ghici după multiplicitatea rădăcinii.
  • dim Ker + dim Im = 3 este verificarea ta gratuită. Dacă nu dă 3, ai greșit rangul.
  • Ker se citește din sistemul omogen, Im din coloane — nu invers.

Diagonalizarea unei matrice 3×3

Model: parțial CC 2022, plus varianta cu parametru din decembrie 2024

Rețeta

  1. det(A − λI) = 0 → polinomul caracteristic → valorile proprii cu multiplicitățile algebrice a(λ).
  2. Pentru fiecare λ: rezolvi (A − λI)v = 0. Multiplicitatea geometrică este g(λ) = 3 − rang(A − λI).
  3. A e diagonalizabilă ⟺ g(λ) = a(λ) pentru toate valorile proprii. Dacă toate λ sunt distincte, e automat diagonalizabilă.
  4. P are vectorii proprii pe coloane, în aceeași ordine în care pui valorile proprii în D. A = PDP⁻¹.

Exemplu rezolvat — fără parametru

Se dă: A = (2 1 −2; 2 3 −4; 1 1 −1). Se cere diagonalizarea.

polinomul caracteristic: λ³ − 4λ² + 5λ − 2 = (λ − 1)²·(λ − 2) λ₁ = 1 cu a = 2, λ₂ = 2 cu a = 1 λ = 1 : A − I = | 1 1 −2 | | 2 2 −4 | rang 1 ⟹ g = 3 − 1 = 2 ✓ = a | 1 1 −2 | Ker : x + y − 2z = 0 ⟹ v₁ = (1,−1,0), v₂ = (2,0,1) λ = 2 : A − 2I = | 0 1 −2 | linia 1: y = 2z | 2 1 −4 | linia 3: x + y − 3z = 0 ⟹ x = z | 1 1 −3 | ⟹ v₃ = (1, 2, 1), g = 1 ✓ = a | 1 2 1 | P = |−1 0 2 | D = diag(1, 1, 2) | 0 1 1 |

Exemplu rezolvat — cu parametru

Se dă: A = (3 β 0; 0 4 1; 0 2 5). Se cere β pentru care A e diagonalizabilă.

Prima coloană dă direct λ = 3. Restul, din blocul 2×2: (4−λ)(5−λ) − 2 = λ² − 9λ + 18 = (λ − 3)(λ − 6) ⟹ λ = 3 cu a = 2, λ = 6 cu a = 1 Diagonalizabilă ⟺ g(3) = 2 ⟺ rang(A − 3I) = 1 : | 0 β 0 | A − 3I = | 0 1 1 | liniile 2 și 3 sunt deja proporționale | 0 2 2 | rangul e 1 doar dacă (0, β, 0) e proporțional cu (0, 1, 1) ⟹ β = 0

Capcane

  • Verifică fiecare vector propriu înlocuindu-l în sistem. Un semn greșit acolo strică tot restul problemei.
  • g(λ) = n − rang(A − λI). Calculează rangul, nu număra „câte soluții par să fie".
  • Ordinea coloanelor lui P trebuie să corespundă ordinii valorilor proprii din D. Dacă le încurci, A = PDP⁻¹ nu mai iese.
